# Checkpoint 4 — Análise de Dados de Energia

## Sobre o projeto

Este repositório contém as resoluções desenvolvidas para o **Checkpoint 4 — Análise de Dados de Energia**, realizado durante as aulas de análise e manipulação de dados.

O objetivo da atividade é aplicar conceitos de **Python, Pandas, análise exploratória de dados, visualização de informações e consumo de APIs**, utilizando diferentes conjuntos de dados relacionados ao setor energético.

As atividades foram desenvolvidas com base nos exercícios propostos nas **Aulas 03 e 04**, contemplando análise, tratamento e interpretação dos dados.

## Estrutura do projeto

O repositório contém os seguintes arquivos:

* `analise_energetica_datasets_1a6.ipynb` — exercícios e análises dos datasets trabalhados durante as aulas.
* `Desafio_Final_Energia_ONS_API_Final.ipynb` — desafio envolvendo dados de energia e consulta de API.
* `Energy Production Dataset.csv` — conjunto de dados sobre produção de energia.
* `Plant_1_Generation_Data.csv` — dados de geração de uma planta de energia.
* `Steel_industry_data.csv` — dados relacionados ao consumo de energia na indústria siderúrgica.
* `Tetuan City power consumption.csv` — dados de consumo de energia da cidade de Tétouan.
* `energydata_complete.csv` — conjunto de dados utilizado para análise de consumo energético.

Os arquivos estão disponíveis diretamente neste repositório.

## Fontes dos dados

Os datasets utilizados na atividade possuem diferentes origens. Entre as fontes utilizadas estão bases públicas e conjuntos de dados disponibilizados para fins educacionais e de análise.

### Operador Nacional do Sistema Elétrico — ONS

Os dados utilizados no desafio envolvendo a API de energia foram obtidos por meio de informações disponibilizadas pelo **Operador Nacional do Sistema Elétrico (ONS)**.

O ONS é responsável pela coordenação e controle da operação das instalações de geração e transmissão do Sistema Interligado Nacional (SIN).

### Outras bases de dados

Também foram utilizados datasets relacionados a:

* Produção de energia;
* Geração de energia solar;
* Consumo de energia elétrica;
* Consumo energético industrial;
* Consumo de energia residencial.

Os arquivos utilizados encontram-se armazenados neste próprio repositório para facilitar a reprodução das análises.

## Objetivo da atividade

A atividade tem como objetivo desenvolver habilidades práticas de **análise de dados**, permitindo transformar dados brutos em informações úteis para interpretação e tomada de decisões.

Por meio das análises realizadas, buscamos compreender padrões de geração e consumo de energia, identificar comportamentos nos dados e utilizar ferramentas computacionais para apresentar os resultados de maneira clara.
